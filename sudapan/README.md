# 수다판 sudapan — 韩式匿名论坛（糯叽机微应用）

氛围参考韩国女性向论坛，路人、你的角色和你本人一起发帖。帖子和评论都是韩语网络用语，并附中文翻译。

## 安装

1. 打开糯叽机：App Store → Apps → 新建 → 空白应用
2. 删掉编辑器里的模板代码，把 `index.html` 的**全部内容**粘进去
3. 保存并运行，在权限框里同意申请的能力（见下表）
4. 想让角色在聊天里聊到论坛：进聊天设定 →「自定义App供稿」→ 勾上 수다판（每个聊天单独设置）

## 功能

- 版块：영화·드라마（影视）/ 잡담（闲聊）/ 연애（情感）/ 심야（深夜，深色主题），外加 HOT 热门榜和全部
- 点 ↻ 刷新：AI 生成一批路人帖（自带几条评论），角色有一定概率以自己的人设发帖
- 帖子详情：推荐、楼层评论、回复某一楼、「看更多评论」，以及「发到聊天」
- 你发帖或评论可以写中文，发布时会改写成韩语网络口吻，并保留中文翻译；可以选匿名或实名
- 角色可匿名或实名：设置里给每个角色配论坛昵称和发言方式（总是匿名 / 有时匿名 / 总是实名）；匿名的角色会带 🔒 标记，点名字能看到是谁（只有你看得到）
- 聊天联动：
  - **供稿**：热帖和你们发过的帖子会告诉角色，角色可以把帖子以卡片形式发给你。角色匿名发的帖子只有 TA 自己知道是 TA 写的
  - **动作**：角色可以在聊天中去수다판发帖、评论，写完会收到回执
  - **提醒**：你发帖后可以「告诉角色」；你回复了角色的评论，下一轮会悄悄提醒 TA

## 申请的权限

| 权限 | 用途 |
|---|---|
| `ai` | 生成帖子、评论、翻译（花你自己的 API 额度，每分钟最多 20 次） |
| `roster.read` | 读取角色名册，并让 AI 以角色人设发言 |
| `feed.publish` | 把论坛内容供稿给角色、发提醒 |
| `feed.actions` | 让角色在聊天中发帖、评论 |
| `chat.send` | 「发到聊天」按钮，把帖子卡片发进聊天 |

不同意某项权限也能用，只是对应功能会失效并给出提示。

## 已知限制

- 每次刷新、发帖、评论都会调用 1～2 次 AI。角色出没频率越高，调用越多
- AI 偶尔会返回格式不对的内容，这时会提示「再刷一次」
- 不会编造真实明星的八卦，八卦类内容使用虚构艺人
- `nuo.chat.sendCard`、`nuo.roster.list` 的返回格式文档没写全，代码按常见格式做了兼容。如果出问题，请看 App 详情页 →「日志」
